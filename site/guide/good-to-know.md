# Good to Know

- **Only administrators can work tickets.** Everyone else sees the report form.
- **Notifications aren't built in yet.** Use an [automation](/guide/events) for now.
- **Label colours** are chosen from a set of names that follow your Home Assistant theme, not any colour you like.
- **Home Desk never starts an AI agent by itself.** **Queue for AI Agent** only marks a ticket. The [optional runner](/runner/) is a separate program you set up yourself.
- **It's a young project.** It's used daily in one home, so rough edges are likely. Please [report anything you find](https://github.com/Greminn/ha-home-desk/issues).
