# Settings

Select the **cog** at the top right of Home Desk. Only administrators see it. Changes save as you make them.

| Setting | What it does |
|---|---|
| **Close resolved tickets** | How long a resolved ticket waits before it closes by itself. |
| **Tickets from Repairs** | Turns Home Assistant Repairs into tickets. See [Repairs](/guide/repairs). |
| **Voice to text** | Whether household voice messages are turned into words. See [Household Reports](/guide/household-reports). |
| **AI Agent** | Which of Home Assistant's AI agents handles **Review with AI**. See [Using AI](/ai/using-ai). |
| **Notifications** | Choices about what each person hears about. These are saved, but nothing is sent yet. See [Automations and Notifications](/guide/events). |

The **⋮** menu in the panel header opens **Manage Labels** and **Manage Categories**.
