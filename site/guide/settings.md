# Settings

The cog in the panel header opens Settings. Administrators only. Changes save immediately.

| Setting | Effect |
|---|---|
| **Close resolved tickets** | The delay before a resolved ticket closes. |
| **Tickets from Repairs** | Opens a ticket for each Home Assistant Repair. See [Repairs](/guide/repairs). |
| **Voice to text** | Transcribes household voice messages. See [Household Reports](/guide/household-reports). |
| **AI Agent** | The AI Task or conversation entity used by **Review with AI**. See [AI Agents](/ai/using-ai). |
| **Notifications** | Each manager's choices. Stored, but nothing is sent yet. See [Automations and Notifications](/guide/events). |

**Manage Labels** and **Manage Categories** are in the **⋮** menu.
